# Home Mail

Лёгкий Gmail-клиент для боковой панели Home Assistant: чтение и отправка писем, локальный кэш, фоновая синхронизация и темы оформления. Вход в интерфейс защищён Home Assistant Ingress; отдельный веб-порт наружу не открывается.

После установки укажите Gmail-адрес и пароль приложения Google на вкладке **Конфигурация**, запустите аддон и откройте **Mail** в боковой панели. Обычный пароль Google не используйте.

Подробные параметры, ограничения и безопасность описаны в [документации](DOCS.md). Исходный код и обратная связь: [BrainDeLook/ha-mail-client](https://github.com/BrainDeLook/ha-mail-client).
